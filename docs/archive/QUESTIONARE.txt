# 11. Existing App Review

These are best answered **after you've designed the product**, because otherwise the existing application starts negotiating for its own continued employment.

For every existing feature/class/page:

**157.** If this did not exist today, **would we deliberately build it again?**

**158.** Does it answer one of the product's core questions?

**159.** Does another feature answer the same question better?

**160.** Is it product functionality, evidence infrastructure, or research?

**161.** If research, why is it in normal navigation?

**162.** If nobody can explain its output without reading source code, should it survive?

**163.** Are we preserving it because it is useful or because it took effort to build?

# 12. Final Priorities

After all of that, classify the resulting **features and decisions**, not individual questions.

## MUST

What TajsTokens fails to be TajsTokens without.

## SHOULD

Important and intended for v1, but not fundamental enough to block the product.

## COULD

Useful ideas worth retaining without committing to implementation.

## WON'T

Things deliberately outside the redesigned product.
